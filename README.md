# Splitwise API

REST API for splitting shared expenses between groups — built with Spring Boot.

## Stack
Java 17, Spring Boot, Spring Data JPA, H2 (dev), Lombok, Maven

## Progress
- [x] Project setup
- [x] Domain model (User, Group, Expense, ExpenseSplit) with JPA relationships
- [x] Repositories (Spring Data JPA)
- [X] Database connection + application.properties config
- [X] Service layer
- [X] REST controllers (CRUD)
- [ ] Authentication (JWT)
- [ ] Advanced splitting logic
- [ ] Debt simplification algorithm
- [ ] Tests
- [ ] Docker + PostgreSQL migration
